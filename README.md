## 🌟 ভিশন ও মিশন (Vision & Mission)

- **ভিশন**: একটি সচেতন, শিক্ষিত, দক্ষ ও মানবিক যুব সমাজ গড়ে তোলা, যারা সমাজে ইতিবাচক নেতৃত্ব দেবে এবং টেকসই উন্নয়ন নিশ্চিত করবে।
- **মিশন**:
  1. যুব ও যুব নারীদের দক্ষতা উন্নয়ন, নেতৃত্ব বিকাশ ও কর্মসংস্থান সহায়তা।
  2. সুবিধাবঞ্চিত শিশুদের শিক্ষা (Project Your Mentor) ও পুষ্টি-স্বাস্থ্য সহায়তা।
  3. জলবায়ু পরিবর্তন মোকাবিলা, ক্লাইমেট অলিম্পিয়াড (COKS), বৃক্ষরোপণ ও পরিবেশ সুরক্ষা।
  4. নারী ক্ষমতায়ন, মাসিক ও মানসিক স্বাস্থ্য সচেতনতা ও জেন্ডার সমতা প্রতিষ্ঠা।
  5. হস্তশিল্প, হ্যান্ড পেইন্ট ও উদ্যোক্তা সৃষ্টিতে প্রশিক্ষণ ও বাজারজাতকরণ সহায়তা।

## 🚀 প্রধান তিনটি ফ্ল্যাগশিপ প্রকল্প (3 Flagship Projects)

1. 📚 **Project Your Mentor (PYM)**:
   - মূলমন্ত্র: *"Every Child is Unique"*
   - সুবিধাবঞ্চিত শিশুদের জন্য শিক্ষা, নৈতিকতা, সৃজনশীল আর্ট ও বিনামূল্যে স্বাস্থ্য পরীক্ষা।
2. 🌍 **Climate Olympiad by Karu Shikha (COKS)**:
   - স্লোগান: *"সবুজে গড়ি ভবিষ্যৎ, সচেতন হই আজ থেকেই।"*
   - স্কুল-কলেজ পর্যায়ে বার্ষিক ক্লাইমেট অলিম্পিয়াড, সিসা দূষণবিরোধী প্রচারণা, বৃক্ষ বিতরণ ও পেপার সিড পেন উৎপাদন।
3. 👩‍💼 **Empowering Women, Growing Safe Future (EWGSF)**:
   - মূলমন্ত্র: *"নারী ক্ষমতায়নই টেকসই উন্নয়ন ও নিরাপদ ভবিষ্যতের চাবিকাঠি"*
   - গ্রামীণ ও যুব নারীদের হ্যান্ড পেইন্ট ও কুটির শিল্প প্রশিক্ষণ, মাসিক স্বাস্থ্য উঠান বৈঠক ও আত্মনির্ভরশীলতা।

## 💻 প্রযুক্তি কাঠামো (Tech Stack)

- **3D Graphics Engine**: [Three.js](https://threejs.org/) (Custom particle system forming official Karu Shikha logo)
- **Styling**: Tailwind CSS (CDN) + Custom Glassmorphism CSS
- **Interactivity**: Vanilla JavaScript (ES6+), Three.js Canvas
- **Typography & Icons**: Hind Siliguri (Bengali font), Inter, SVG Icons
- **Responsive Architecture**: Mobile-First, Touch-optimized, Zero-overflow guaranteed

## 📱 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 🎨 **ইন্টারঅ্যাক্টিভ থ্রি-ডি হিরো ব্যাকগ্রাউন্ড**: কারু শিখার আসল লোগো স্পেসিয়াল পার্টিকেল এফেক্ট ও মাউস/টাচ প্যারালাক্স সহ মসৃণভাবে আবর্তিত হয়।
- 📜 **সরকারি নিবন্ধন সনদ লাইটবক্স**: নিবন্ধন নম্বর `যুউঅ-৯৭`-এর স্ক্যান কপি সরাসরি ওয়েবসাইটে ফুলস্ক্রিন দেখা ও ডাউনলোডের সুবিধা।
- 📊 **৬৭টি ফিল্ড অ্যাক্টিভিটি এক্সপ্লোরার**: ২০১৯ সাল থেকে সংগঠনের সমস্ত ফিল্ড ক্যাম্পেইনের ক্যাটাগরি ফিল্টার ও রিয়েলটাইম লাইভ সার্চ।
- 👥 **সদস্যবৃন্দ ডিরেক্টরি**: ৭ কার্যনির্বাহী ও ২৫ সাধারণ সদস্যের লাইভ ডাটাবেজ, সার্চ বার এবং ট্যাপ-টু-কল সুবিধা।
- 🗺️ **ইন্টারেক্টিভ গুগল ম্যাপস**: প্রতিষ্ঠানের লক্ষ্মীপুর কার্যালয়ের লাইভ গুগল ম্যাপ আইফ্রেম ও নেভিগেশন লিংক।
- 📸 **২৫টি হাই-রেজুলেশন স্থিরচিত্র গ্যালারি**: ফিল্ড অ্যাকশনের আসল ছবি ক্যাটাগরি অনুযায়ী ফিল্টার ও প্রিভিউ।
- 🌐 **দ্বিভাষিক ইন্টারফেস (Bilingual BN/EN)**: এক ক্লিকে বাংলা ও ইংরেজি ভাষার মধ্যে পরিবর্তন।
- 💖 **ডোনেশন ও ভলান্টিয়ার মডাল**: অনলাইন অনুদান ও স্বেচ্ছাসেবী আবেদনের সুবিন্যস্ত ডায়ালগ।

## 🚀 লোকাল রান করার নিয়ম (How to Run Locally)

যেকোনো লোকাল স্ট্যাটিক সার্ভার দিয়ে প্রজেক্টটি সরাসরি রান করা যাবে:

```bash
# প্রজেক্ট ডিরেক্টরিতে যান
cd youth-empowerment-3d

# Python ৩ দিয়ে সার্ভার চালু করুন (পোর্ট ৮০০৮ বা যেকোনো পোর্ট)
python3 -m http.server 8008

# এরপর ব্রাউজারে প্রবেশ করুন:
http://localhost:8008
```

অথবা সরাসরি `index.html` ফাইলটি যেকোনো আধুনিক ব্রাউজারে ডাবল ক্লিক করে ওপেন করতে পারেন।

## 📤 গিটহাবে আপলোড করার নিয়ম (Push to GitHub)

আপনার গিটহাব একাউন্টে প্রজেক্টটি আপলোড করতে নিচের কমান্ডগুলো চালান:

```bash
# ১. গিটহাবে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: karu-shikha-web)
# ২. এরপর টার্মিনালে নিচের কমান্ডগুলো একে একে রান করুন:

cd youth-empowerment-3d
git init
git add .
git commit -m "Initial commit: Karu Shikha Youth Development Society 3D Web Experience"
git branch -M main

# ৩. আপনার গিটহাব রিপোজিটরি লিংক দিয়ে রিমোট অ্যাড করুন:
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git

# ৪. গিটহাবে পুশ করুন:
git push -u origin main
```

### 🌐 GitHub Pages-এ ফ্রি লাইভ হোস্টিং:
1. GitHub Repository-তে গিয়ে **Settings** ট্যাবে যান।
2. বাঁপাশের মেনু থেকে **Pages** অপশনে ক্লিক করুন।
3. **Build and deployment**-এর অধীনে Source হিসেবে **Deploy from a branch** নির্বাচন করুন।
4. Branch হিসেবে **`main`** এবং ফোল্ডার হিসেবে **`/ (root)`** সিলেক্ট করে **Save** করুন।
5. ১-২ মিনিটের মধ্যে আপনার ফ্রি লাইভ ওয়েবসাইট লিঙ্ক তৈরি হয়ে যাবে (যেমন: `https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/`)!
